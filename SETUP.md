## How to upload (2 minutes)

1. Go to https://github.com/nexauraconsultant/tagwebsit/upload/main
2. Drag in all 9 files from this zip (unzip first, then drag the whole
   contents, not the zip file itself)
3. If it asks to replace existing files (index.html, tags.json, logo files),
   say yes / confirm - that's expected, it's replacing the old broken versions
4. Scroll down, write any commit message, click Commit changes
5. Wait ~1 minute, then open your live site and hard-refresh (Ctrl+Shift+R or
   Cmd+Shift+R) to clear any cached old version

## Adding/removing tags after this

1. Click Manager Login (top right of the site)
2. Paste your GitHub personal access token (must have Contents: Read+write
   access scoped to the tagwebsit repo)
3. Tick "Remember on this device" so you don't need to paste it every time
4. Use Add a tag to add a new project, or the X next to any tag in the
   list to remove one
5. Every change is a real commit - you can see it in the repo's commit history
